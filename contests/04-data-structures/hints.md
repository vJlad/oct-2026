# 04. Деревья отрезков — подсказки

## A. Time to reap the harvest

1. Формула `Σ max(a_i - L, 0)` — это сумма только по тем кустам, что выше `L`.
2. Отсортируйте высоты один раз, посчитайте суффиксные суммы. На запрос —
   `upper_bound(L)`, дальше `suffix[idx] - L * count`.

## B. Memory Manager

1. Нужен «ближайший свободный к `h`» среди занятых/свободных. Держите
   множество свободных страниц.
2. Кандидатов всего два: `lower_bound(h)` и предыдущий элемент. Сравните
   расстояния, при равенстве берите меньший номер.

## C. Just another array problem

1. Массив всё время остаётся циклическим сдвигом исходного отсортированного.
   Достаточно хранить величину сдвига.
2. Для запроса найдите `lower_bound(x)` в исходном массиве, переведите индекс
   в текущий через сдвиг. Отдельно разберите случай, когда блок одинаковых
   значений «разрезан» сдвигом — тогда первое вхождение имеет индекс 1.

## D. High Load Database

1. Для фиксированного `t` — обычная жадность: набираем транзакции, пока
   сумма не превысит `t`; переход к следующей — бинпоиском по префиксам.
2. Запросов много, но `t` повторяются — запоминайте ответ. Оценка:
   на каждое новое `t` нужно `~sum/t` переходов, суммарно `sum·H(n)`.

## E. Financial Discipline

1. Деньги обновляются как `m = max(0, m + a_i - X)`. Раскрутите рекурсию:
   ответ — максимум по суффиксам от `Σ(a_i) - X·len`.
2. Значит `answer(X) = max_j ( (S_n - S_j) - X·(n - j) )` — это максимум
   линейных функций от `X`. Стройте верхнюю огибающую (CHT) и отвечайте
   за `O(log n)` или сортировкой запросов.

## F. Mex and Cards

1. Сумма мексов = `Σ_k` (число куч с мексом больше `k`). Куч с мексом > `k`
   не больше, чем `min(c_0..c_k)`, где `c_v` — количество карт значения `v`.
2. Держите массив `pref[k] = min(c_0..c_k)` в дереве отрезков с `assign`
   на отрезке и суммой. При изменении `c_v` меняется только участок
   `[v, p)`, где `p` — первая позиция с `c_p <` нового значения.

## G. Army Creation

1. Запрос `[l, r]`: сколько различных чисел, если каждое разрешено не более
   `k` раз. Подумайте, как свести это к подсчёту позиций.
2. Для каждой позиции `i` найдите `p_i` — позицию `k`-го предыдущего
   вхождения того же числа (или 0). Тогда ответ — число `i ∈ [l, r]`
   с `p_i < l`. Это делается персистентным ДО по префиксам.

## H. Points

1. Запрос: среди точек с `x > X` и `y > Y` найти минимальную по `x`,
   при равенстве — минимальную по `y`.
2. Сожмите `x`. В дереве отрезков по `x` храните максимум `y` в узле.
   Спуск находит первый `x > X` с `max y > Y`; среди точек этого `x`
   берите минимальную `y > Y` (например, `set` на каждый `x`).
