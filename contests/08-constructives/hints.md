# 08. Конструктивы — подсказки

## A. Pills

1. Одно взвешивание — значит вес должен кодировать номер бутылки.
2. Возьмите из `i`-й бутылки ровно `i` пилюль. Тогда вес равен
   `500·Σi + i_фальшивой` (фальшивая тяжелее на 1 мг). Разность и есть номер.

## B. Composite Coloring

1. Нужно раскрасить числа так, чтобы в одном цвете у всех был общий делитель
   больше 1. Достаточно смотреть на наименьший простой делитель.
2. Числа до 1000 имеют простой делитель не больше 31 — это 11 простых.
   Цвет = номер наименьшего простого делителя.

## C. Problem on array

1. Можно потратить `N` запросов на чтение всего массива — тогда сортировка
   известна.
2. Остаётся не больше `N` запросов на `swap`. Перестановку раскладываем
   на циклы: каждый цикл длины `L` чинится за `L−1` обмен, всего ≤ `N−1`.

## D. Guess the K-th Zero

1. Запрос даёт сумму на отрезке, значит можно узнать число нулей
   на префиксе: `mid − sum(1..mid)`.
2. Это монотонная функция от `mid`. Бинпоиск по `mid`: ищем минимальный,
   где нулей уже `≥ k`.

## E. String Equality

1. Обмены соседних символов делают важным только количество каждой буквы.
2. Идите по алфавиту: если букве `c` не хватает до нужного количества —
   ответ `No`. Излишек можно превратить в пары `c+1` (операция увеличивает
   две одинаковые буквы). Значит излишек должен быть чётным, и половина
   уходит в следующую букву.

## F. Eight-Connected Figures

1. Нужны `n` клеток одного цвета, связанных по 8-соседству. Цвет клетки
   узнаётся запросом.
2. Спросите клетку, затем обходите в ширину её соседей, спрашивая только
   новых: клетки того же цвета добавляйте, остальные запоминайте как
   «другого цвета». При `p = 1/2` компонента огромна — `n ≤ 300` наберётся
   за считанные сотни запросов.

## G. Engineer Artem

1. Нужно, чтобы любые две соседние клетки различались. Достаточно сделать
   их разными по чётности.
2. Прибавьте 1 к тем клеткам, у которых `a[i][j] % 2 != (i+j) % 2`.
   Тогда у соседей чётности разные, значит и значения разные.
