# 08. Конструктивы — подсказки

## A. Pills

1. Одно взвешивание — значит вес должен кодировать номер бутылки.
2. Возьмите из `i`-й бутылки ровно `i` пилюль: вес равен `500·Σi + i`.
   Разность и есть номер фальшивой бутылки.

## B. Encode and Decode (Easy)

1. Программа запускается дважды, и память между запусками теряется.
   Единственный канал — напечатанная строка `s`.
2. В лёгкой версии `a_i ≤ 26`, значит каждый элемент — одна буква
   (`a` соответствует 1, `z` — 26). Длина строки автоматически равна `n`.
   Второй запуск просто переводит буквы обратно.

## C. Composite Coloring

1. Нужно, чтобы у чисел одного цвета был общий делитель больше 1 —
   достаточно наименьшего простого делителя.
2. Числа до 1000 имеют простой делитель не больше 31, это 11 простых.
   Цвет = номер наименьшего простого делителя.

## D. Problem on array

1. Потратьте `N` запросов на чтение массива — дальше сортировка известна.
2. Остаётся ≤ `N` запросов на `swap`. Раскладывайте перестановку на циклы:
   цикл длины `L` чинится за `L−1` обмен.

## E. Guess the K-th Zero

1. Запрос даёт сумму на отрезке, значит число нулей на префиксе —
   `mid − sum(1..mid)`.
2. Функция монотонна: бинпоиск по `mid`, ищем минимальный с `≥ k` нулями.

## F. String Equality

1. Обмены соседних символов делают важным только количество каждой буквы.
2. Идите по алфавиту: если буквы не хватает — `No`. Излишек переносится
   в следующую букву парами, значит он должен быть чётным.

## G. Eight-Connected Figures

1. Нужны `n` клеток одного цвета, связных по 8-соседству.
2. Спросите клетку и обойдите в ширину соседей, спрашивая только новые.
   При `p = 1/2` компонента огромна — `n ≤ 300` наберётся за сотни запросов.

## H. Engineer Artem

1. Достаточно сделать соседние клетки разными по чётности.
2. Прибавьте 1 там, где `a[i][j] % 2 != (i+j) % 2`. У соседей чётности
   разные, значит значения разные.

## I. Oriented Journey

1. Канал между запусками — сами рёбра: в первом запуске их выдают по одному,
   во втором они приходят в том же порядке. Значит `i`-е ребро несёт `i`-й бит.
2. Договоритесь о кодировке бита: если бит 1 — печатайте ребро меньшей меткой
   вперёд, если 0 — большей. Декодер читает направление каждой строки
   и складывает биты в число `s`.
