# 02. Геометрия — подсказки

## A. Bounding Boxes

1. Коробку можно вращать, но рёбра остаются параллельны — значит важен
   только набор измерений, а не их порядок.
2. Отсортируйте три измерения каждой коробки по возрастанию. Ответ —
   произведение поэлементных минимумов по всем коробкам.

## B. Rectangle Restoration

1. У прямоугольника стороны `(a, a, b, b)`. Выпишите, какие значения могут
   принимать сумма двух сторон и сумма трёх.
2. Возможных пар всего три вида: `(2a, 2a+b)`, `(2a, a+2b)`, `(a+b, 2a+b)`.
   Для каждой выразите `a, b` через `x, y`, проверьте положительность
   и возьмите минимум периметра.

## C. Points and Minimum Distance

1. Длина пути не меньше суммы размаха по `x` и размаха по `y`.
2. Отсортируйте все `2n` чисел. Отдайте первые `n` под `x`, последние `n`
   под `y`: ответ `(a[n-1]-a[0]) + (a[2n-1]-a[n])`, точки `(a[i], a[n+i])`.

## D. Rectangles

1. Внешнее кольцо `w×h` — это `2w + 2h - 4` клеток, внутренность —
   `(w-2)(h-2)`.
2. Обозначьте `a = w-2`, `b = h-2`. Условие превращается в
   `(a-2n)(b-2n) = 4n(n+1)`. Переберите делители правой части — их надо
   получить из разложения `n` и `n+1` на простые.

## E. Ideal Pyramid

1. Пирамида с уклоном 45° в точке `(x, y)` имеет высоту
   `h - max(|x-xc|, |y-yc|)`.
2. Бинпоиск по `h`. Проверка: для каждого обелиска нужно
   `|x_i - xc| ≤ h - h_i` и `|y_i - yc| ≤ h - h_i`, то есть пересечение
   отрезков по `x` и по `y` непусто.

## F. Polygons

1. Многоугольник `A` строго выпуклый и обходится по часовой стрелке —
   значит точка внутри, если она «справа» от каждого ребра.
2. Проверять все рёбра за `O(n)` на точку слишком долго. Найдите сектор
   бинпоиском по углу от `A[0]`, затем проверьте одно ребро. Граница
   не считается «внутри».

## G. 1%-Euclidean

1. Точный ответ требует `O(n^2)` пар — это `10^11` при `n = 5·10^5`.
   Но точность нужна всего 1%.
2. Оцените среднее расстояние по случайной выборке пар (порядка `10^6`),
   умножьте на число пар `n(n-1)/2`. Для маленьких `n` считайте точно.
