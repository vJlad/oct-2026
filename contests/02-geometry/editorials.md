# 02. Геометрия — разборы

## A. Inscribed Circle (102215L)

Максимальная окружность внутри линзы двух окружностей. Для точки `P`
максимальный радиус окружности с центром в `P`, лежащей в обоих кругах:

```
g(P) = min(r1 − |P − c1|, r2 − |P − c2|)
```

Если `P` смещён с прямой центров на `h` (проекция `x`), то
`|P − c1| = sqrt(x² + h²) ≥ x`, поэтому

```
g(P) ≤ min(r1 − x, r2 − (d − x)) ≤ (r1 + r2 − d) / 2
```

Значит центр лежит на отрезке `c1c2`, и максимум — там, где ограничения
равны:

```
R = (r1 + r2 − d) / 2,   P = c1 + (c2 − c1)·(r1 − R)/d
```

Проверка касания: `|P − c1| + R = r1`, `|P − c2| + R = r2`. Пример:
`(0,0,5)`, `(6,0,5)` → `R = 2`, центр `(3,0)`.

Сложность `O(1)`. Точность `1e-9`: `long double`, 15 знаков.
Ловушка: искать окружность, касающуюся линзы «сбоку» — оценка выше
показывает, что это не лучше.

## B. New Year Table (140A)

Тарелки радиуса `r` на столе радиуса `R`, каждая касается края → центры
на окружности радиуса `R − r`.

- `n = 1`: нужно `r ≤ R`.
- `n = 2`: центры на противоположных концах диаметра, нужно
  `2(R − r) ≥ 2r`, то есть `R ≥ 2r`.
- `n ≥ 3`: центры — правильный `n`-угольник на окружности `R − r`,
  соседние не пересекаются, если хорда не меньше `2r`:

```
2(R − r)·sin(π/n) ≥ 2r   ⟺   r ≤ R·sin(π/n) / (1 + sin(π/n))
```

Сложность `O(1)`. Ловушка: применять общую формулу при `n = 1`
(при `n = 2` она случайно совпадает, при `n = 1` — нет).

## C. Alley (104805E)

Центры на одной прямой, расстояние между любыми двумя кругами не меньше
большего радиуса. Сортируем по `x`.

**Лемма.** Несоседние круги не пересекаются: для `i < j < k`
`|x_k − x_i| ≥ max(r_i,r_j) + max(r_j,r_k) ≥ r_i + r_k`.

Значит пересекаются только соседние и тройных пересечений нет:

```
S = Σ π·r_i² − Σ площадь_линзы(i, i+1)
```

по парам с `|x_i − x_{i+1}| < r_i + r_{i+1}`, где

```
cos α = (d² + a² − b²)/(2da),  cos β = (d² + b² − a²)/(2db)
S = a²α + b²β − ½·sqrt((−d+a+b)(d+a−b)(d−a+b)(d+a+b))
```

Сложность `O(n log n)`. `long double`, `π = acos(-1.0L)`.
Ловушка: складывать линзы по всем парам.

## D. Area of Two Circles' Intersection (600D)

`d` — расстояние между центрами, `r1 ≥ r2`.

1. `d ≥ r1 + r2` — ответ `0`.
2. `d ≤ r1 − r2` — ответ `π·r2²`.
3. Иначе:

```
α = acos((d² + r1² − r2²)/(2·d·r1))
β = acos((d² + r2² − r1²)/(2·d·r2))
S = r1²α + r2²β − ½·sqrt((−d+r1+r2)(d+r1−r2)(d−r1+r2)(d+r1+r2))
```

Сложность `O(1)`. Координаты до `1e9` → `d²` до `4·10^18`, только
`long double`. Ловушка: случай «внутри» проверить до общей формулы,
иначе `acos` получит аргумент вне `[−1, 1]`.

## E. Mike and Geometry Problem (689E)

Нужно `Σ по всем k-подмножествам |пересечение|`. Перебирать подмножества
нельзя, но видно, что вклад зависит только от того, сколько отрезков
покрывают точку: если точку покрывают `c` отрезков, она входит
в `C(c, k)` пересечений.

Сканлайн: события `l` (+1) и `r+1` (−1) — именно `r+1`, потому что точки
целые и отрезок `[l, r]` содержит `r − l + 1` точку. Сортируем события
по координате; на полуинтервале `[x_i, x_{i+1})` покрытие `c` постоянно,
вклад — `(x_{i+1} − x_i) · C(c, k)`.

`C(c, k)` считаются заранее факториалами по модулю `1e9+7` (или обратными
элементами). Сложность `O(n log n)`.

Ловушки: взять `r` вместо `r+1` (теряются крайние точки) и забыть,
что при `c < k` вклад нулевой.

## F. Rectangle Puzzle (280A)

Оба прямоугольника выпуклые, с общим центром в нуле. Вместо вывода формулы
для каждого угла надёжнее отсечение: берём первый прямоугольник как
многоугольник и отсекаем его четырьмя полуплоскостями второго
(Sutherland–Hodgman). Остаётся выпуклый многоугольник, его площадь —
формулой Гаусса (шнуровка).

Угол `α` переводим в радианы, углы поворота второго прямоугольника —
`±α`. При `α ∈ {0, 90, 180}` всё работает без особых случаев.

Сложность `O(1)` (четыре отсечения по ≤ 8 вершинам).
Ловушка: писать отдельные формулы для «повёрнутый внутри», «крест»,
«уголки» — их легко перепутать, а отсечение всегда верно.

## G. Nature Reserve (1059D)

Окружность имеет ровно одну общую точку с `y = 0`, значит касается прямой.
Если есть точки и с `y > 0`, и с `y < 0` — ответ `-1`. Иначе отражаем всё
в верхнюю полуплоскость.

При радиусе `R` центр обязан быть в `(x, R)`. Точка `(x_i, y_i)` внутри:

```
(x − x_i)² + (y_i − R)² ≤ R²   ⟺   (x − x_i)² ≤ 2R·y_i − y_i²
```

Отсюда `R ≥ y_i/2` и

```
x ∈ [ x_i − sqrt(2R·y_i − y_i²),  x_i + sqrt(2R·y_i − y_i²) ]
```

Предикат «все отрезки пересекаются» монотонен по `R`, поэтому бинпоиск.
`lo = max(y_i)/2`, `hi` — удвоением до выполнимости; `~100` итераций.

Сложность `O(n · iter)`. Ловушки: корень из отрицательного (нет проверки
`R ≥ y_i/2`) и центр не на высоте `R`.

## H. Ice Cream (102862E)

Конус — равнобедренный треугольник с вершиной в начале координат, высотой
`h` и полушириной `a = w/2`. Боковая стенка — отрезок от `(0,0)` до
`(a, h)`, то есть прямая `x = k·y`, где `k = a/h = w/(2h)`.
Мороженое налито до `y = l`, поверхность — отрезок `[−kl, kl]`.

**Симметрия.** Шарики одинаковые, значит их центры `(±d, l + R)`.
Они не пересекаются при `d ≥ R`, а расстояние до стенки уменьшается
с ростом `d`, поэтому оптимально `d = R` (шарики касаются в точке
`(0, l + R)`).

**Точки касания мороженого.** Шарик касается поверхности в `(±R, l)`,
и эта точка должна лежать на самом мороженом:

```
R ≤ k·l
```

**Стенка.** Нужно, чтобы расстояние от центра `P = (R, l + R)` до отрезка
стенки было не меньше `R`. Ближайшая точка отрезка — либо внутренняя
(перпендикуляр), либо угол `(a, h)`. Отсюда две конфигурации.

*Конфигурация 1: перпендикуляр внутрь отрезка.*

```
(k(l + R) − R) / sqrt(1 + k²) = R
R1 = k·l / ( sqrt(1 + k²) + 1 − k )
```

*Конфигурация 2: ближайшая точка — угол рожка.*

```
(R − a)² + (l + R − h)² = R²
R2 = a + (h − l) − sqrt(2·a·(h − l))
```

**Ответ.** Для каждого кандидата проверяем два условия: `R ≤ k·l` и
`расстояние(P(R), стенка) ≥ R`. Берём наибольший из подошедших.

Пример из условия (`h = 10`, `l = 8`, `w = 8`, значит `k = 0.4`, `a = 4`):

- `R1 = 3.2 / (sqrt(1.16) + 0.6) = 1.908131846` — подходит;
- `R2 = 4 + 2 − sqrt(16) = 2` — не подходит: перпендикуляр попадает внутрь
  отрезка, и расстояние до стенки там `1.857 < 2`.

Ответ `1.908131846` — совпадает с примером.

**Почему не бинпоиск.** Множество допустимых `R` не монотонно: после
конфигурации 2 шарик «переваливает» через угол и снова становится
допустимым при бо́льших `R` (пока не сработает `R ≤ k·l`). Поэтому
именно разбор двух конфигураций, а не предикат.

Сложность `O(1)` на тест. Ловушка: считать, что шарики касаются только
прямой (бесконечной) стенки, и не проверять, что точка касания лежит
на отрезке.

# Бонус (вне контеста)

## Rectangles (102788B)

Внешних клеток `2w + 2h − 4`, внутренних `(w−2)(h−2)`. После замены
`a = w−2`, `b = h−2`:

```
(a − 2n)(b − 2n) = 4n(n+1)
```

Перебираем делители `4n(n+1)`, полученные из разложения `n` и `n+1`
на простые, берём `d ≤ √(4n(n+1))`, стороны `(d+2n+2, 4n(n+1)/d+2n+2)`.

## Convex Interval — почему не включена

Очевидное решение — «максимальный отрезок подряд идущих поворотов одного
знака» — неверно. Контрпример из условия:

```
(-1,0) (0,0) (1,1) (1,-1) (0,1) (1,0)
```

Последние пять точек: все векторные произведения одного знака, но стороны
пересекаются, то есть это не многоугольник, и официальный ответ — 3, а не 5.
Корректное решение требует проверки простоты, это уровень 2200+.
