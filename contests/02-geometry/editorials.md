# 02. Геометрия — разборы

## A. New Year Table (140A)

Тарелки радиуса `r` на столе радиуса `R`, каждая касается края → центры
на окружности радиуса `R − r`.

- `n = 1`: нужно `r ≤ R`.
- `n = 2`: центры на противоположных концах диаметра, нужно
  `2(R − r) ≥ 2r`, то есть `R ≥ 2r`.
- `n ≥ 3`: центры — правильный `n`-угольник на окружности `R − r`,
  соседние не пересекаются, если хорда не меньше `2r`:

```
2(R − r)·sin(π/n) ≥ 2r   ⟺   r ≤ R·sin(π/n) / (1 + sin(π/n))
```

Сложность `O(1)`. Ловушка: применять общую формулу при `n = 1`
(при `n = 2` она случайно совпадает, при `n = 1` — нет).

## B. Alley (104805E)

Центры на одной прямой, расстояние между любыми двумя кругами не меньше
большего радиуса. Сортируем по `x`.

**Лемма.** Несоседние круги не пересекаются: для `i < j < k`
`|x_k − x_i| ≥ max(r_i,r_j) + max(r_j,r_k) ≥ r_i + r_k`.

Значит пересекаются только соседние, тройных пересечений нет:

```
S = Σ π·r_i² − Σ площадь_линзы(i, i+1)
```

по парам с `|x_i − x_{i+1}| < r_i + r_{i+1}`, где

```
cos α = (d² + a² − b²)/(2da),  cos β = (d² + b² − a²)/(2db)
S = a²α + b²β − ½·sqrt((−d+a+b)(d+a−b)(d−a+b)(d+a+b))
```

Сложность `O(n log n)`. `long double`, `π = acos(-1.0L)`.
Ловушка: складывать линзы по всем парам.

## C. Area of Two Circles' Intersection (600D)

`d` — расстояние между центрами, `r1 ≥ r2`.

1. `d ≥ r1 + r2` — ответ `0`.
2. `d ≤ r1 − r2` — ответ `π·r2²`.
3. Иначе:

```
α = acos((d² + r1² − r2²)/(2·d·r1))
β = acos((d² + r2² − r1²)/(2·d·r2))
S = r1²α + r2²β − ½·sqrt((−d+r1+r2)(d+r1−r2)(d−r1+r2)(d+r1+r2))
```

Сложность `O(1)`. Координаты до `1e9` → `d²` до `4·10^18`, только
`long double`. Ловушка: случай «внутри» проверить до общей формулы,
иначе `acos` получит аргумент вне `[−1, 1]`.

## D. Mike and Geometry Problem (689E)

Нужно `Σ |пересечение| по всем k-подмножествам`. Перебирать подмножества
нельзя, но вклад зависит только от кратности покрытия: точка, покрытая `c`
отрезками, входит в `C(c, k)` пересечений.

Сканлайн: события `l` (+1) и `r+1` (−1) — именно `r+1`, потому что точки
целые и отрезок `[l, r]` содержит `r − l + 1` точку. Сортируем события;
на полуинтервале `[x_i, x_{i+1})` покрытие `c` постоянно, вклад —
`(x_{i+1} − x_i) · C(c, k)`.

`C(c, k)` считаются заранее факториалами по модулю `1e9+7`.
Сложность `O(n log n)`.

Ловушки: взять `r` вместо `r+1`; забыть, что при `c < k` вклад нулевой.

## E. Rectangle Puzzle (280A)

Оба прямоугольника выпуклые, с общим центром в нуле. Вместо формулы для
каждого угла — отсечение: берём первый прямоугольник как многоугольник
и отсекаем его четырьмя полуплоскостями второго (Sutherland–Hodgman).

**Как работает отсечение.** Многоугольник задан списком вершин против
часовой стрелки. Для каждого ребра `A → B` второго прямоугольника оставляем
точки слева от него: `cross(B − A, P − A) ≥ 0`. Идём по вершинам текущего
многоугольника и для каждой пары соседей `P, Q`:

- `P` внутри, `Q` внутри → оставляем `Q`;
- `P` внутри, `Q` снаружи → оставляем точку пересечения `PQ` с прямой `AB`;
- `P` снаружи, `Q` внутри → оставляем точку пересечения и `Q`;
- обе снаружи → ничего.

После четырёх отсечений остаётся выпуклый многоугольник; площадь —
формулой Гаусса (шнуровка): `½|Σ (x_i·y_{i+1} − x_{i+1}·y_i)|`.

Угол `α` переводим в радианы, второй прямоугольник повёрнут на `±α`.
При `α ∈ {0, 90, 180}` всё работает без особых случаев.

Сложность `O(1)` (четыре отсечения по ≤ 8 вершин). Ловушка: писать
отдельные формулы для «внутри», «крест», «уголки» — их легко перепутать,
а отсечение верно всегда.

## F. Polygons (166B)

`A` строго выпуклый, обход по часовой стрелке → точка `P` внутри, если
`cross(A[i+1] − A[i], P − A[i]) < 0` для всех рёбер.

Перебирать все рёбра на каждую из `m` вершин — `2·10^9`, не проходит.
Пользуемся выпуклостью: из `A[0]` проводим веер диагоналей.

**Проверка одной точки `P`.**

1. Если `cross(A[1] − A[0], P − A[0]) ≥ 0` или
   `cross(A[n−1] − A[0], P − A[0]) ≤ 0` — `P` вне угла при вершине `A[0]`,
   ответ `NO` (нулевое произведение означает точку на луче — тоже `NO`).
2. Бинпоиском по `i ∈ [1, n−2]` находим сектор: ищем наибольшее `i` с
   `cross(A[i] − A[0], P − A[0]) < 0` (функция монотонна по `i`, так как
   многоугольник выпуклый).
3. Проверяем ребро сектора: `cross(A[i+1] − A[i], P − A[i]) < 0`.

Если все три условия выполнены — `P` строго внутри. Поскольку `B` —
простой многоугольник, а `A` выпуклый, проверки всех вершин `B` достаточно:
рёбра `B` целиком лежат внутри.

Сложность `O(m log n)`. Ловушки: не обработать точки вне угла между
`A[1]` и `A[n−1]`; и перепутать знак из-за направления обхода (при обходе
против часовой все неравенства меняются на `>`).

## G. Nature Reserve (1059D)

Окружность имеет ровно одну общую точку с `y = 0`, значит касается прямой.
Если есть точки и с `y > 0`, и с `y < 0` — ответ `-1`. Иначе отражаем всё
в верхнюю полуплоскость.

При радиусе `R` центр обязан быть в `(x, R)`. Точка `(x_i, y_i)` внутри:

```
(x − x_i)² + (y_i − R)² ≤ R²   ⟺   (x − x_i)² ≤ 2R·y_i − y_i²
```

Отсюда `R ≥ y_i/2` и

```
x ∈ [ x_i − sqrt(2R·y_i − y_i²),  x_i + sqrt(2R·y_i − y_i²) ]
```

Предикат «все отрезки пересекаются» монотонен по `R`, поэтому бинпоиск:
`lo = max(y_i)/2`, `hi` — удвоением до выполнимости, `~100` итераций.

Сложность `O(n · iter)`. Ловушки: корень из отрицательного (нет проверки
`R ≥ y_i/2`) и центр не на высоте `R`.

## H. Ice Cream (102862E)

Конус — равнобедренный треугольник с вершиной в начале координат, высотой
`h` и полушириной `a = w/2`. Стенка — отрезок от `(0,0)` до `(a, h)`,
то есть прямая `x = k·y`, где `k = a/h = w/(2h)`. Мороженое налито до
`y = l`, поверхность — отрезок `[−kl, kl]`.

**Симметрия.** Шарики одинаковые → центры `(±d, l + R)`. Они не пересекаются
при `d ≥ R`, а расстояние до стенки падает с ростом `d`, поэтому оптимально
`d = R` (шарики касаются в `(0, l + R)`).

**Точки касания мороженого.** Шарик касается поверхности в `(±R, l)`,
и эта точка должна лежать на самом мороженом: `R ≤ k·l`.

**Стенка.** Нужно, чтобы расстояние от `P = (R, l + R)` до отрезка стенки
было не меньше `R`. Ближайшая точка — либо внутренняя (перпендикуляр),
либо угол `(a, h)`. Отсюда две конфигурации.

*Перпендикуляр внутрь отрезка:*

```
(k(l + R) − R) / sqrt(1 + k²) = R
R1 = k·l / ( sqrt(1 + k²) + 1 − k )
```

*Ближайшая точка — угол рожка:*

```
(R − a)² + (l + R − h)² = R²
R2 = a + (h − l) − sqrt(2·a·(h − l))
```

**Ответ:** для каждого кандидата проверяем `R ≤ k·l` и
`расстояние(P(R), стенка) ≥ R`, берём наибольший подошедший.

Пример (`h = 10`, `l = 8`, `w = 8` → `k = 0.4`, `a = 4`):
`R1 = 3.2 / (sqrt(1.16) + 0.6) = 1.908131846` подходит;
`R2 = 4 + 2 − sqrt(16) = 2` не подходит — перпендикуляр попадает внутрь
отрезка, и расстояние до стенки там `1.857 < 2`. Ответ совпадает с примером.

**Почему не бинпоиск.** Множество допустимых `R` не монотонно: после
конфигурации 2 шарик «переваливает» через угол и снова становится
допустимым при бо́льших `R` (пока не сработает `R ≤ k·l`).

Сложность `O(1)` на тест. Ловушка: считать, что стенка — бесконечная
прямая, и не проверять, что точка касания лежит на отрезке.
