# 02. Геометрия — разборы

## A. Bounding Boxes (106193B)

Коробку можно поворачивать, но стороны остаются параллельны сторонам
упаковки. Значит коробка с измерениями `(a,b,c)` помещается в упаковку
`(w,h,d)` тогда и только тогда, когда отсортированные по возрастанию
тройки сравнимы покоординатно.

Отсортируем измерения каждой упаковки. Сувенирная коробка должна влезать
во все упаковки, поэтому её отсортированные измерения — поэлементные
минимумы: `min_w · min_h · min_d`. Больше объёма не получить: любое
измерение упирается в одну из упаковок.

Сложность `O(n)`. Ловушка: брать минимум по каждой позиции без сортировки —
тогда `(2,10,10)` и `(3,8,4)` дают неправильный ответ.

## B. Rectangle Restoration (104015D)

Стороны прямоугольника — `a, a, b, b`. Сумма двух сторон принимает одно
из значений `2a`, `a+b`, `2b`; сумма трёх — `2a+b` или `a+2b`.
Разных итоговых случаев три (остальные симметричны):

| Случай | `a`, `b` | Периметр | Условие |
|---|---|---|---|
| `x=2a`, `y=2a+b` | `x/2`, `y-x` | `2y-x` | `y > x` |
| `x=2a`, `y=a+2b` | `x/2`, `(y-x/2)/2` | `x/2 + y` | `y > x/2` |
| `x=a+b`, `y=2a+b` | `y-x`, `2x-y` | `2x` | `x < y < 2x` |

Берём минимум по допустимым случаям (условия строгие, стороны
положительны), печатаем с точностью `1e-4`. Если ни один не подошёл — `-1`.

Сложность `O(1)`. Ловушка: считать, что `x` и `y` — обязательно «две разные»
и «три разные» стороны; важны только значения сумм.

## C. Points and Minimum Distance (104777I)

Нижняя оценка: путь, обходящий точки, обязан «покрыть» размах по `x`
и размах по `y`, поэтому его длина не меньше
`(max x - min x) + (max y - min y)`.

Все `2n` чисел раздаются в `x` и `y`. Чтобы минимизировать сумму размахов,
разобьём отсортированный массив на две половины: первые `n` чисел — `x`,
последние `n` — `y`. Оценка становится
`(a[n-1]-a[0]) + (a[2n-1]-a[n])`, и она достижима: точки `(a[i], a[n+i])`,
выписанные по возрастанию `i`, дают путь, где обе координаты монотонно
растут.

Сложность `O(n log n)`. Ловушка: вывести точки в произвольном порядке —
путь станет длиннее оценки.

## D. Alley (104805E)

Все центры на одной прямой, расстояние между любыми двумя кругами не меньше
большего радиуса. Отсортируем по `x`.

**Лемма.** Несоседние круги не пересекаются. Для `i < j < k` выполнено
`|x_j - x_i| ≥ max(r_i, r_j) ≥ r_i` и `|x_k - x_j| ≥ max(r_j, r_k) ≥ r_k`,
значит `|x_k - x_i| ≥ r_i + r_k`.

Следствие: пересекаются только соседние круги, тройных пересечений нет.
Значит

```
S = Σ π·r_i² − Σ площадь_линзы(i, i+1)
```

по тем соседним парам, где `|x_i - x_{i+1}| < r_i + r_{i+1}`.

Площадь линзы двух кругов радиусов `a`, `b` на расстоянии `d`:

```
cos α = (d² + a² − b²) / (2da),   cos β = (d² + b² − a²) / (2db)
S = a²·α + b²·β − ½·sqrt((−d+a+b)(d+a−b)(d−a+b)(d+a+b))
```

Сложность `O(n log n)`. Точность: `long double`, `π = acos(-1.0L)`.
Ловушка: складывать линзы по всем парам; при касании площадь линзы ноль.

## E. Inscribed Circle (102215L)

Даны две окружности, пересекающиеся в двух точках. Нужна максимальная
окружность внутри линзы — то есть внутри обоих кругов.

Пусть центры `c1`, `c2`, радиусы `r1`, `r2`, `d = |c1c2|`. Для точки `P`
максимальный радиус окружности с центром в `P`, лежащей в обоих кругах:

```
g(P) = min(r1 − |P − c1|, r2 − |P − c2|)
```

**Где оптимум.** Если `P` смещён с прямой центров на `h` (проекция `x`),
то `|P − c1| = sqrt(x² + h²) ≥ x`, поэтому

```
g(P) ≤ min(r1 − x, r2 − (d − x)) ≤ (r1 + r2 − d) / 2
```

— смещение только уменьшает радиус. Значит центр лежит на отрезке `c1c2`,
и максимум достигается там, где два ограничения равны:
`r1 − x = r2 − (d − x)`.

**Ответ.** `R = (r1 + r2 − d) / 2`, центр — на расстоянии
`x = (r1 − r2 + d) / 2` от `c1`:

```
P = c1 + (c2 − c1) · (x / d)
```

Проверка касания: `|P − c1| + R = r1` и `|P − c2| + R = r2`, обе окружности
касаются изнутри. Пример: `(0,0,5)`, `(6,0,5)` → `R = 2`, центр `(3,0)`.

Точность `1e-9`: считать в `long double`, печатать 15 знаков.
Ловушка: пытаться вписать окружность, касающуюся линзы «сбоку» —
и симметрия, и оценка выше показывают, что это не лучше.

## F. Ideal Pyramid (104874I)

Пирамида с уклоном 45° и центром `(xc, yc)` в точке `(x, y)` имеет высоту
`h - max(|x - xc|, |y - yc|)`. Условие «обелиск внутри»:

```
max(|x_i - xc|, |y_i - yc|) ≤ h - h_i
```

то есть `xc ∈ [x_i - (h-h_i), x_i + (h-h_i)]` и аналогично по `y`.
Для фиксированного `h` проверка — непустое пересечение отрезков по `x`
и по `y`.

Условие монотонно по `h`, поэтому бинпоиск от `max h_i` до `4·10^8`.
Центр — любая точка пересечения, например левые концы отрезков.

Сложность `O(n log C)`. Ловушка: считать, что высота убывает как евклидово
расстояние, — тогда условие станет `sqrt(dx²+dy²) ≤ h-h_i` и ответ будет
другим.

## G. Area of Two Circles' Intersection (600D) — crossover

`d` — расстояние между центрами, `r1 ≥ r2` после возможного обмена.

1. `d ≥ r1 + r2` — не пересекаются, ответ `0`.
2. `d ≤ r1 − r2` — меньший круг внутри, ответ `π·r2²`.
3. Иначе — линза:

```
α = acos((d² + r1² − r2²) / (2·d·r1))
β = acos((d² + r2² − r1²) / (2·d·r2))
S = r1²·α + r2²·β − ½·sqrt((−d+r1+r2)(d+r1−r2)(d−r1+r2)(d+r1+r2))
```

Сложность `O(1)`. Координаты до `1e9`, значит `d²` до `4·10^18` — считать
в `long double`. Ловушка: проверить случай «один внутри другого» до общей
формулы, иначе `acos` получит аргумент вне `[−1, 1]`.

## H. Polygons (166B) — crossover

`A` строго выпуклый, обход по часовой стрелке, значит точка `P` внутри,
если она строго справа от каждого ребра:
`cross(A[i+1]-A[i], P-A[i]) < 0`.

Проверять все рёбра на каждую вершину — `2·10^9` операций, не проходит.
Используем выпуклость: из `A[0]` проводим веер диагоналей, бинпоиском
по углу находим сектор `[A[0], A[i], A[i+1]]`, затем проверяем одно ребро
`A[i] → A[i+1]` и две крайние диагонали. Неравенства строгие: точка
на границе даёт `NO`.

Сложность `O(m log n)`. Ловушка: не обработать точки вне угла между
`A[1]` и `A[n-1]`.

## I. 1%-Euclidean (104848I) — crossover

Точный ответ — сумма `n(n-1)/2` корней, при `n = 5·10^5` это `1.25·10^11`
слагаемых. Требуется точность 1%, и этим надо воспользоваться.

Оценка Монте-Карло: `M` случайных пар, среднее расстояние `avg`,
ответ `avg · n(n-1)/2`. Стандартная ошибка среднего падает как `1/√M`:
при `M = 10^6` относительная ошибка порядка `10^{-3}`.

Практика: фиксированный seed, `M = min(n(n-1)/2, 10^6)`, для `n ≤ 3000`
точный двойной цикл. Сложность `O(n + M)`.

Ловушка: искать точный алгоритм и застрять; и брать пары неравномерно
(только соседние после сортировки) — смещение не скомпенсируется.

# Бонус (вне контеста)

## Rectangles (102788B)

Внешних клеток у `w×h`: `2w + 2h - 4`, внутренних: `(w-2)(h-2)`.
Условие «внутренних в `n` раз больше» даёт после замены `a = w-2`, `b = h-2`:

```
(a - 2n)(b - 2n) = 4n(n+1)
```

Перебираем делители `4n(n+1)`, полученные из разложения `n` и `n+1`
на простые, берём `d ≤ √(4n(n+1))`, стороны `(d+2n+2, 4n(n+1)/d+2n+2)`.
Сложность `O(√n + τ log τ)`.

## New Year Table (140A)

Тарелки радиуса `r` на столе радиуса `R`, каждая обязана касаться края,
значит центр каждой лежит на окружности радиуса `R − r`.

- `n = 1`: нужно `r ≤ R`.
- `n = 2`: центры можно поставить на противоположных концах диаметра,
  нужно `2(R − r) ≥ 2r`, то есть `R ≥ 2r`.
- `n ≥ 3`: центры образуют правильный `n`-угольник на окружности радиуса
  `R − r`; соседние не пересекаются, если хорда не меньше `2r`:

```
2(R − r)·sin(π/n) ≥ 2r   ⟺   r ≤ R·sin(π/n) / (1 + sin(π/n))
```

Это ровно тот случай «разные конфигурации», что и в «Мороженом»: формула
зависит от того, какое ограничение связывает. Сложность `O(1)`.
Ловушка: применить общую формулу при `n = 2` (синус даёт `r ≤ R/2`,
что совпадает, но при `n = 1` формула ломается).
