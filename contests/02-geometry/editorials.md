# 02. Геометрия — разборы

## A. Bounding Boxes (106193B)

Коробку можно поворачивать, но стороны остаются параллельны сторонам
упаковки. Значит коробка с измерениями `(a,b,c)` помещается в упаковку
`(w,h,d)` тогда и только тогда, когда отсортированные по возрастанию
тройки сравнимы покоординатно.

Отсортируем измерения каждой упаковки; сувенирная коробка — поэлементные
минимумы, ответ `min_w · min_h · min_d`. Больше не получить: любое измерение
упирается в одну из упаковок.

Сложность `O(n)`. Ловушка: брать минимум по каждой позиции без сортировки.

## B. Rectangle Restoration (104015D)

Стороны прямоугольника — `a, a, b, b`. Сумма двух сторон — одно из
`2a`, `a+b`, `2b`; сумма трёх — `2a+b` или `a+2b`. Разных случаев три:

| Случай | `a`, `b` | Периметр | Условие |
|---|---|---|---|
| `x=2a`, `y=2a+b` | `x/2`, `y-x` | `2y-x` | `y > x` |
| `x=2a`, `y=a+2b` | `x/2`, `(y-x/2)/2` | `x/2 + y` | `y > x/2` |
| `x=a+b`, `y=2a+b` | `y-x`, `2x-y` | `2x` | `x < y < 2x` |

Берём минимум по допустимым, печатаем с точностью `1e-4`.
Сложность `O(1)`. Ловушка: считать, что `x` и `y` — обязательно разные
наборы сторон; важны только значения сумм.

## C. Points and Minimum Distance (104777I)

Нижняя оценка: путь покрывает размах по `x` и по `y`, значит его длина
не меньше `(max x − min x) + (max y − min y)`.

Разбиваем отсортированные `2n` чисел на две половины: первые `n` — `x`,
последние `n` — `y`. Оценка `(a[n-1]−a[0]) + (a[2n-1]−a[n])` достижима:
точки `(a[i], a[n+i])` в порядке возрастания `i` дают монотонный путь.

Сложность `O(n log n)`. Ловушка: вывести точки в произвольном порядке.

## D. Alley (104805E)

Центры на одной прямой, расстояние между любыми двумя кругами не меньше
большего радиуса. Отсортируем по `x`.

**Лемма.** Несоседние круги не пересекаются: для `i < j < k`
`|x_k − x_i| ≥ max(r_i,r_j) + max(r_j,r_k) ≥ r_i + r_k`.

Значит пересекаются только соседние, тройных пересечений нет:

```
S = Σ π·r_i² − Σ площадь_линзы(i, i+1)
```

по парам с `|x_i − x_{i+1}| < r_i + r_{i+1}`, где

```
cos α = (d² + a² − b²)/(2da),  cos β = (d² + b² − a²)/(2db)
S = a²α + b²β − ½·sqrt((−d+a+b)(d+a−b)(d−a+b)(d+a+b))
```

Сложность `O(n log n)`. `long double`, `π = acos(-1.0L)`.

## E. Ideal Pyramid (104874I)

Пирамида с уклоном 45°: высота в точке `(x, y)` равна
`h − max(|x−xc|, |y−yc|)`. Условие «обелиск внутри»:

```
max(|x_i − xc|, |y_i − yc|) ≤ h − h_i
```

то есть `xc` лежит в `[x_i − (h−h_i), x_i + (h−h_i)]`, аналогично `yc`.
Проверка для фиксированного `h` — непустое пересечение отрезков по `x`
и по `y`. Монотонно по `h` → бинпоиск от `max h_i` до `4·10^8`.

Сложность `O(n log C)`. Ловушка: евклидово расстояние вместо `max`.

## F. Area of Two Circles' Intersection (600D) — crossover

`d` — расстояние между центрами, `r1 ≥ r2`.

1. `d ≥ r1 + r2` — ответ `0`.
2. `d ≤ r1 − r2` — ответ `π·r2²`.
3. Иначе:

```
α = acos((d² + r1² − r2²)/(2·d·r1))
β = acos((d² + r2² − r1²)/(2·d·r2))
S = r1²α + r2²β − ½·sqrt((−d+r1+r2)(d+r1−r2)(d−r1+r2)(d+r1+r2))
```

Сложность `O(1)`. Координаты до `1e9` → `d²` до `4·10^18`, только
`long double`. Ловушка: случай «внутри» проверить до общей формулы,
иначе `acos` получит аргумент вне `[−1, 1]`.

## G. Polygons (166B) — crossover

`A` строго выпуклый, обход по часовой стрелке → точка внутри, если
`cross(A[i+1]−A[i], P−A[i]) < 0` для всех рёбер.

Перебирать все рёбра — `2·10^9`. Бинпоиск по углу от `A[0]` находит сектор
`[A[0], A[i], A[i+1]]`, затем проверяем одно ребро и две диагонали.
Все неравенства строгие.

Сложность `O(m log n)`. Ловушка: точки вне угла между `A[1]` и `A[n−1]`.

## H. Nature Reserve (1059D) — crossover

Окружность имеет ровно одну общую точку с `y = 0`, значит она касается
прямой. Если среди точек есть и `y > 0`, и `y < 0` — ответ `-1`
(касающаяся окружность лежит по одну сторону). Иначе отражаем всё в
верхнюю полуплоскость.

Радиус `R` → центр обязан быть в `(x, R)`. Точка `(x_i, y_i)` внутри:

```
(x − x_i)² + (y_i − R)² ≤ R²   ⟺   (x − x_i)² ≤ 2R·y_i − y_i²
```

Отсюда `R ≥ y_i/2` и

```
x ∈ [ x_i − sqrt(2R·y_i − y_i²),  x_i + sqrt(2R·y_i − y_i²) ]
```

Проверка: пересечение всех отрезков непусто. Предикат монотонен по `R`
(больше радиус — шире каждый отрезок), поэтому бинпоиск.

Границы: `lo = max(y_i)/2`, `hi` — удвоением, пока не станет выполнимо
(хватает `~10^14`). Итераций `~100` для `1e-6`.

Сложность `O(n · iter)`. Ловушки: забыть `R ≥ y_i/2` (корень из
отрицательного), и считать, что центр можно ставить не на высоте `R`.

## I. 1%-Euclidean (104848I) — crossover

Точный ответ — `n(n−1)/2` корней, при `n = 5·10^5` это `1.25·10^11`
слагаемых. Нужна точность 1% — используем оценку Монте-Карло: `M` случайных
пар, среднее `avg`, ответ `avg · n(n−1)/2`. Ошибка среднего `~1/√M`:
при `M = 10^6` это `~10^{-3}`.

Практика: фиксированный seed, `M = min(n(n−1)/2, 10^6)`, для `n ≤ 3000`
точный двойной цикл. Сложность `O(n + M)`.

Ловушка: искать точный алгоритм; и брать пары неравномерно.

# Бонус (вне контеста)

## Inscribed Circle (102215L)

Максимальная окружность внутри линзы двух окружностей. Для точки `P`
максимальный радиус `g(P) = min(r1 − |P−c1|, r2 − |P−c2|)`. Если `P` смещён
с прямой центров на `h` при проекции `x`, то `|P−c1| = sqrt(x²+h²) ≥ x`,
поэтому

```
g(P) ≤ min(r1 − x, r2 − (d − x)) ≤ (r1 + r2 − d)/2
```

— оптимум на отрезке `c1c2`, в точке `R = (r1+r2−d)/2`, центре
`P = c1 + (c2−c1)·(r1−R)/d`. Вся задача — одна формула, поэтому в контест
не попала; как разминка на 5 минут — отлично.

## Rectangles (102788B)

Внешних клеток `2w+2h−4`, внутренних `(w−2)(h−2)`. После замены `a = w−2`,
`b = h−2`:

```
(a − 2n)(b − 2n) = 4n(n+1)
```

Перебираем делители `4n(n+1)` (из разложения `n` и `n+1`), берём
`d ≤ √(4n(n+1))`, стороны `(d+2n+2, 4n(n+1)/d+2n+2)`.

## New Year Table (140A)

Тарелки радиуса `r` на столе радиуса `R`, каждая касается края → центры
на окружности радиуса `R−r`.

- `n = 1`: `r ≤ R`.
- `n = 2`: `2(R−r) ≥ 2r`, то есть `R ≥ 2r`.
- `n ≥ 3`: `2(R−r)·sin(π/n) ≥ 2r` ⟺ `r ≤ R·sin(π/n)/(1+sin(π/n))`.

Ровно тот случай «разные конфигурации», что и в «Мороженом».
