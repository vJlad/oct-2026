# 06. Потоки — подсказки

## A. Treasure Island

1. Нужно отделить левый верхний угол от правого нижнего, удаляя клетки.
   По Менгеру это минимум вершинного разреза = максимум вершинно-непере­
   секающихся путей.
2. Ответ всегда `0`, `1` или `2`. Стройте поток с раздвоением клетки
   (вход → выход, ёмкость 1) и смотрите величину потока: 0 — уже разделено,
   1 — хватает одной клетки, 2 — нужно две.

## B. Soldier and Traveling

1. Солдат из города либо остаётся, либо уходит в соседний — это поток.
   Ограничение `a_i` стоит на городе (вершине), а не на дороге.
2. Раздвоите города: `исток → i` с `a_i`, `i → i'` (остаться) и `i → j'`
   по дорогам с бесконечностью, `i' → сток` с `b_i`. Ответ «YES», если
   поток равен `Σ b_i` (и `Σ a_i = Σ b_i`).

## C. Flawed Flow

1. Поток уже задан: для каждой вершины известно, сколько должно вытекать.
   Сориентировать рёбра можно обходом от стока.
2. Направляйте каждое ребро «к уже обработанной вершине» и копите выходящий
   поток второго конца. Когда у вершины набрался её требуемый поток —
   кладите её в очередь.

## D. Array and Operations

1. Пары с нечётной суммой индексов дают двудольный граф (чётные против
   нечётных). Операция делит оба числа на общий простой.
2. Для каждого простого `p` отдельно: `исток → нечётные` (степень `p`),
   `нечётные → чётные` по парам с `∞`, `чётные → сток` (степень `p`).
   Суммируйте потоки.

## E. Delivery Bears

1. Медведи несут одинаковый груз `x`; через ребро ёмкости `c` проходит
   не больше `⌊c/x⌋` медведей.
2. Бинпоиск по `x`: сеть с ёмкостями `⌊c_i/x⌋`, проверка — поток `≥ b`.

## F. Petya and Graph

1. Доход — веса выбранных рёбер, расход — веса задетых вершин.
   Это maximum weight closure.
2. `исток → ребро` весом `w_e`; ребро → обе вершины с `∞`; вершина → сток
   весом `a_v`. Ответ `Σ w_e − mincut`.

## G. Biologist

1. Разрез: сторона истока — «самец», сторона стока — «самка»; смена пола —
   стоимость ребра к нужной стороне.
2. Требование «все самцы» — узел с `исток → r` (премия) и `r → животные`
   с `∞`; «все самки» — зеркально. Штраф за нарушение прибавьте к весу
   ребра премии.

## H. Card Game

1. Уровень монотонен: если при уровне `L` колода набирается, то и при
   большем тоже. Бинпоиск по `L`.
2. Для фиксированного `L` нужно максимальное суммарное могущество без пар
   с простой суммой магических чисел. Сумма двух чётных или двух нечётных
   больше 2 не бывает простой, поэтому конфликты почти двудольные:
   чётные против нечётных. Отдельно разберитесь с картами, у которых
   магическое число равно 1 (`1 + 1 = 2` — простое).
