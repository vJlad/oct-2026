# 06. Потоки — подсказки

## A. Flawed Flow

1. Поток уже задан: для каждой вершины известно, сколько должно вытекать.
   Нужно только сориентировать рёбра.
2. Идите от стока `n`: каждое неориентированное ребро направляйте «к уже
   обработанной вершине» и копите выходящий поток второго конца. Как только
   у вершины набрался её требуемый поток — кладите её в очередь.

## B. Array and Operations

1. Пары `(i, j)` с нечётной суммой индексов — это двудольный граф
   (чётные против нечётных). Операция делит оба числа на общий простой.
2. Для каждого простого `p` отдельно: `исток → нечётные` с пропускной
   способностью «степень `p` в числе», `нечётные → чётные` по рёбрам пар
   с бесконечностью, `чётные → сток` со степенью `p`. Суммируйте потоки
   по всем `p`.

## C. Delivery Bears

1. Медведи несут одинаковый груз `x`. Через ребро пропускной способности
   `c` проходит не больше `⌊c / x⌋` медведей.
2. Бинпоиск по `x`: строим сеть с пропускными способностями `⌊c_i / x⌋`
   и проверяем, что максимальный поток `≥ b`.

## D. Petya and Graph

1. Доход — сумма весов выбранных рёбер, расход — веса вершин, которые эти
   рёбра задевают. Это maximum weight closure.
2. Исток → ребро с весом `w_e`; ребро → обе вершины с `∞`; вершина → сток
   с весом `a_v`. Ответ `Σ w_e − mincut`.

## E. Biologist

1. У каждого животного два состояния (самец/самец-самка) и стоимость смены
   пола. Требования «все из набора — самцы» или «все — самки» дают
   премию/штраф.
2. Разрез: сторона истока — «самец», сторона стока — «самка». Стоимость
   смены — ребро от истока (если сейчас самец) или к стоку. Требование —
   отдельный узел с ребром `∞` к своим животным и весом премии к
   соответствующей стороне.
