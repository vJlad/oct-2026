# 01. Математика — разборы

## A. Adventure in Flatland (104842A)

Платить приходится только при проходе через точки, у которых хотя бы одна
координата равна нулю, то есть через оси (и начало координат).

- Если `x1·x2 > 0` и `y1·y2 > 0` — обе точки в одном квадранте, отрезок
  между ними не пересекает оси: ответ 0.
- Иначе квадранты разные, и любая кривая обязана задеть ось: ответ 1.
  Одного прохода достаточно — например, через начало координат (это одна
  платная точка) или через одну точку на оси.

Сложность `O(1)`. Ловушка: сравнивать координаты «больше/меньше» вместо
знаков — тогда ломается на отрицательных числах.

## B. Divisibility Trick (104772D)

Нужно число `n`, делящееся на `d`, у которого сумма цифр тоже делится на `d`.

Возьмём десятичную запись `d` и повторим её `d` раз. Такое число равно
`d · (10^{k(r-1)} + ... + 10^k + 1)`, где `k` — длина записи `d`,
`r = d` — число повторов, то есть оно делится на `d`. Сумма цифр равна
`d · s(d)`, где `s(d)` — сумма цифр `d`, и тоже делится на `d`.

Длина: `d · len(d) ≤ 1000 · 4 = 4000` цифр — с запасом меньше `10^6`.
Отдельный случай `d = 1` — подходит любое положительное число.

Сложность `O(d log d)`. Ловушка: попытаться вывести `d` и добить нулями —
сумма цифр при этом не меняется и на `d` не делится.

## C. Integer Square (104013I)

Квадрат с целочисленными вершинами задаётся стороной-вектором `(a, b)`
(целые `a, b`), вторая сторона — поворот на 90°: `(-b, a)`.
Площадь равна `a^2 + b^2`. Значит, задача сводится к представлению `s`
суммой двух квадратов.

Перебираем `a` от 0 до `√s` (при `s ≤ 1000` это 32 итерации), считаем
`b^2 = s - a^2`, проверяем, что это полный квадрат. Если нашли —
вершины `(0,0), (a,b), (-b,a), (a-b,a+b)`; координаты по модулю не больше
`2·31`, ограничение `10^9` не мешает. Иначе печатаем `Impossible`
(например, `s = 3`).

Сложность `O(√s)`. Ловушка: искать только «ровные» квадраты со сторонами
вдоль осей — тогда `s = 5` объявляется невозможным, хотя ответ
`(0,0), (2,1), (-1,2), (1,3)`.

## D. Halfway There (104011H)

Если `gcd(k, n) = 1`, то и `gcd(n-k, n) = 1`, поэтому список взаимно простых
чисел симметричен относительно `n/2`. Количество таких чисел `φ(n)` чётно
при `n > 2`, медиана (нижняя из двух средних) — это наибольшее число,
меньшее `n/2` и взаимно простое с `n`.

- `n` нечётно: `(n-1)/2` всегда подходит, так как `gcd(k, 2k+1) = 1`.
- `n` чётно: идём от `n/2 - 1` вниз, пока не встретим взаимно простое.
  Чётные числа отсеиваются сразу, дальше мешают только нечётные делители
  `n`, поэтому шагов очень мало.
- `n = 2`: единственное число `1`, ответ `1`.

Сложность: `O(log n)` на тест (плюс несколько `gcd`). Ловушка: считать,
что медиана — это `n/2`; для чётного `n` число `n/2` не взаимно просто с `n`.

## E. Remainders Game (687B) — crossover

Остатки `x mod c_i` определяют `x mod k` тогда и только тогда, когда
`k` делит `L = lcm(c_1, ..., c_n)`: если `k | L`, то `x mod k` восстанавливается
по `x mod L`, а иначе найдутся два числа, совпадающие по всем `c_i`,
но различные по модулю `k`.

Считать `L` целиком нельзя (переполнение), да и не нужно. Разложим `k`
на простые: `k = Π p^e`. Условие `k | L` равносильно тому, что для каждого
`p^e` найдётся `c_i`, делящееся на `p^e` (именно тогда в НОК войдёт нужная
степень).

Сложность: `O(√k + n·ω(k))`, где `ω(k) ≤ 9` для `k ≤ 10^9`.
Ловушка: считать НОК «с обрезкой» по `k` — так теряется делимость.

## F. Deep Primes (104842D)

Свойство «глубокой простоты» относится к десятичной записи, поэтому
ограничение `10^18` обманчиво: подходящих чисел конечное число.

1. Каждая цифра — простое число, значит цифры только `2, 3, 5, 7`.
2. Каждая пара соседних цифр — простое двузначное, значит допустимые
   переходы: `2→3`, `3→7`, `5→3`, `7→3`.
3. Каждая тройка подряд — простое трёхзначное. Из допустимых цепочек
   это только `373` (`237 = 3·79`, `537 = 3·179`, `737 = 11·67`).
4. Четвёрка тогда обязана быть `3737 = 37·101` — не простое.
   Значит длина не больше трёх.

Ответ: количество чисел из множества `{2, 3, 5, 7, 23, 37, 53, 73, 373}`,
попавших в `[n, m]`. Сложность `O(1)`. Ловушка: писать перебор с
Миллером–Рабином и не доказать конечность.

## G. Game With Stones (104842G)

Пересыпание камней по соседним коробкам на прямой — это классический
«транспорт на линии». Минимальное число ходов из `a` в `b` равно
`W(a,b) = Σ_i |A_i - B_i|`, где `A`, `B` — префиксные суммы распределений.

Тогда сумма по всем `k` распределениям распадается на независимые
по позициям задачи: для каждой `i` нужно выбрать `B_i`, минимизируя
`Σ_j |A^j_i - B_i|`. Минимум суммы модулей достигается в медиане,
то есть `B_i` — медиана значений `A^j_i` по всем `j`.

Осталось перейти обратно к распределению: `b_i = B_i - B_{i-1}`.
Оно автоматически неотрицательно: каждая `A^j` не убывает, значит и медиана
не убывает.

Сложность: `O(n·k log k)` (сортировка `k` значений на каждую позицию) —
при `n, k ≤ 1000` это ~10^7. Ловушка: считать `W` жадно по парам коробок
вместо префиксных сумм.

## H. Pisano period (104454C)

Период Пизано для простого `p` делит:

- `p - 1`, если `p ≡ ±1 (mod 5)`;
- `2p + 2`, если `p ≡ ±2 (mod 5)`;
- особые случаи: `π(2) = 3`, `π(5) = 20`.

Берём кандидат `C`, факторизуем его пробным делением до `√C ≈ 44721`.
Дальше идём по простым делителям `q` и, пока `d/q` тоже является периодом,
делим `d` на `q`. Проверка «является ли `t` периодом» — это
`F_t ≡ 0 (mod p)` и `F_{t+1} ≡ 1 (mod p)`, то есть быстрое удвоение
Фибоначчи за `O(log t)`.

Сложность: `O(√C + ω(C)·log C·log C)`. Ловушка: проверять только
`F_t ≡ 0` — этого мало (нужно, чтобы пара `(0,1)` вернулась);
и не обработать `p = 2` и `p = 5`.
