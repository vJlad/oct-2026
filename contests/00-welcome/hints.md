# 00. Welcome Round — подсказки

По две подсказки на задачу: первая — куда смотреть, вторая — почти решение.
Можно выдавать сразу, можно открывать по таймеру (например, через 40 минут).

## A. Сбалансированный массив

1. Первую половину можно собрать как угодно удобно — главное, чтобы вторая
   половина состояла из нечётных и давала ту же сумму.
2. Возьмите чётные `2, 4, ..., n`. Из нечётных возьмите `1, 3, 5, ...`
   (на один меньше), а последний элемент положите равным разности сумм.
   Проверьте, когда эта разность окажется чётной.

## B. Игра на палиндроме (простая версия)

1. Всё определяется количеством нулей и тем, симметричны ли они.
2. Разберите три случая: один ноль; чётное число нулей; нечётное число
   нулей больше единицы. В первом и втором Алиса выиграть не может.

## C. Праздник

1. В одной группе не может быть начальника и подчинённого, то есть людей
   с разной глубиной.
2. Ответ — максимальная глубина вершины в лесу (корни — те, у кого `p = -1`).

## D. Каникулы

1. Важно только последнее занятие, а не вся история.
2. `dp[i][0/1/2]` — минимум отдыха, если в день `i` был отдых / контест /
   спорт. Переходы по тому, что разрешено в день `i`.

## E. Максимальная медиана

1. Ответ монотонен: если медиану `x` получить можно, то и любую меньшую — тоже.
2. Бинпоиск по `x`. Проверка: отсортируйте, поднимайте элементы начиная
   с позиции `n/2` до `x`, складывайте `max(0, x - a[i])`, сравнивайте с `k`.

## F. Путешествие

1. Мат. ожидание длины = сумма по рёбрам вероятностей того, что по ребру
   пройдут.
2. DFS из корня: `p[v] = p[u] / (deg(u) - 1)` для некорневых вершин,
   а для корня делить надо на `deg(root)`. Ответ — `Σ p[v]`.

## G. Ксюша и битовые операции

1. Операция зависит от уровня: нижний — `OR`, следующий — `XOR`, и так далее.
2. Постройте дерево отрезков (или просто массив размера `2^(n+1)`), в узле
   храните значение, а операцию определяйте по глубине узла. Обновление —
   подъём от листа к корню.

## H. Шоколадный заяц

1. Максимум перестановки `n` ищется сравнением: из `a mod b` и `b mod a`
   больший ответ соответствует меньшему числу.
2. Найдите позицию `n` за `n-1` сравнение, дальше для каждого `i` один запрос
   `(i, pos_n)` даёт `p_i`, потому что `p_i < n`.

## I. Game With Array

1. Хочется, чтобы суммы подотрезков принимали как можно меньше значений.
2. Если `S < 2N` — ответа нет. Иначе массив `1, 1, ..., 1, S-N+1`, а `K = N`:
   суммы подотрезков — это либо числа `1..N-1`, либо числа `S-N+1 .. S`.

## J. Ghosts

1. Все призраки в момент съёмки лежат на одной прямой, поэтому встреча
   двух призраков — это условие на их скорости.
2. Встреча возможна тогда и только тогда, когда `Vy - a*Vx` совпадает.
   Пары с полностью совпадающими `(Vx, Vy)` встретиться не могут — их
   надо вычесть.
