# Тренировочные контесты, осень 2026

9 контестов для индивидуальной подготовки студентов уровня 1/4 — 1/2 ICPC.
Задачи взяты из официальных контестов ICPC (NERC: 1/4 финала, 1/8 финала,
региональные отборы), плюс несколько задач из раундов Codeforces как «crossover».

## Формат

| Параметр | Значение |
|---|---|
| Задач | 7–8 (в welcome — 10) |
| Время | 3 часа |
| Режим | индивидуальный, ICPC-скоринг |
| Условия | welcome — русский, остальные — английский |
| Разборы | русский, два уровня подсказок |

Лестница сложности внутри контеста: A — вход на 5–15 минут, B–C — база темы,
D–E — ядро, F–G — сложные, H — на дорешивание (за 3 часа её берут редко,
и это нормально).

## Что лежит в папке контеста

- `README.md` — таблица задач, ссылки, баланс контеста, что обсудить после.
- `hints.md` — по две подсказки на задачу. Можно отдавать студентам сразу
  или открывать по таймеру.
- `editorials.md` — полный разбор: идея, алгоритм, сложность, ловушки.
  Держите у себя до разбора.

## Как собрать mashup

1. Codeforces → **Mashups** → *Create new mashup*.
2. Добавить задачи по ссылкам из `README.md` (гимзадачи добавляются по URL,
   обычные — по ID).
3. Настройки: duration `3:00`, режим `ICPC`, штраф стандартный.
4. Язык условий: у гимнзадач английский; в welcome оставить русский.
5. Интерактивные задачи работают в mashup, но нужно не забыть `flush`.

## Про источники

Основной пул — официальные ICPC-контесты NERC (Northeastern Europe):
Moscow Subregional, Northern Subregional, Southern & Volga Regional,
Central Russia Regional, Kyrgyzstan Qualification (1/8 финала).

У задач из gym нет рейтинга Codeforces, поэтому сложность оценивается по
трём сигналам: доля сдавших внутри самого контеста, разбор, собственная
проверка решения. Оценки в таблицах — ориентир, а не рейтинг.

Часть задач помечена как `crossover`: они не из темы контеста, но тренируют
тот же тип мышления. Это сделано намеренно — чтобы учить не «узнавать тему»,
а выбирать метод.
